# 사진판정소 v2.5.0 — 사람의 눈(취향 연구실) 연구 및 안전 통합

## 출발점 (2026-10-31)
- 기존 기본 브랜치는 사진판정소 v2.5.0. 기존 GO/HOLD/DROP, 로컬 판정기록, 신의 눈, 찰나의 선택, 사진보정소를 유지한다.
- 기술적 선명도와 감성적 사진 선호는 다르다. 기존 신의 눈/찰나의 선택은 기술 품질 판단에 우선 사용한다.
- 이번 분기는 자동 AI 심미 점수 대신 사람의 직접 선택을 저장하는 검증 가능한 실험 모듈을 제공한다.

## 학술 근거 (원문 확인)

- Kong et al. (ECCV 2016, AADB): 내용/속성/상대적 미학 순위를 함께 학습, https://doi.org/10.1007/978-3-319-46448-0_40
- Leder et al. (Frontiers in Psychology 2022): 사진의 첫인상과 공유·보관 판단은 개념적으로 구분, https://doi.org/10.3389/fpsyg.2022.786977
- Yang et al. (CVPR 2026): 비슷한 시리즈에서 미적 미세 차이를 판정하기 위한 pairwise 비교 및 순위 학습, https://openaccess.thecvf.com/content/CVPR2026/html/Yang_Fine-grained_Image_Aesthetic_Assessment_Learning_Discriminative_Scores_from_Relative_Ranks_CVPR_2026_paper.html

## 시험판 구현
- 기존 페이지가 제공하는 window.__photoJudgeIntegration.getAllFiles()를 읽기 전용으로 호출한다.
- PC의 자동 셀렉 툴바와 모바일 메뉴에 '사람의 눈' 버튼 추가.
- 인접 촬영시각(2분 이내) 또는 연속 파일번호가 가까운 사진을 먼저 쌍으로 제안한다. 이는 **메타데이터 기반 근사**이며 실제 시각 유사성 검출은 미구현이다.
- 좌우 위치를 무작위로 배치하고 A / B / 비슷하다 / 건너뛰기 기록. 첫인상 또는 다시 보고 싶은 사진과 선택 이유를 별도 기록한다.
- 같은 이미지 집합에서 기록된 선택을 Elo 갱신(K=24)으로 순위화한다. 단, Elo는 연구팀의 검증된 미적 점수 모델이 아니며, 선택자가 1명이라면 1명의 취향만 반영한다.
- 평가 반응 시간(ms)을 수집한다. 사용자가 정확히 3초 내에 판단한다는 가정은 하지 않는다.
- photoJudge.tasteLab.v1 로컬 스토리지에 따로 저장하고 CSV 내보내기 제공. CSV에는 파일명/상대경로가 포함되므로 외부 공유 전 확인이 필요하다.
- 원본 파일 변경·삭제, 기존 판정 기록 수정, 자동 GO/HOLD/DROP 확정, 서버 이미지 전송 기능은 없다.

## 한계 및 판정 정책
- 현재 시스템의 '사람의 눈' 순위는 **사람이 직접 선택해서 만든 기록**이지 자동 미적 추론이 아니다.
- 재현성, 다수 평가자 합의도, 장르별 선호 정확도, 촬영 의도/개인적 가치 보존은 아직 검증 전이다.
- 실제 '일반인의 와, 잘 찍었다' 예측을 만들려면 국내 일반 평가자 집단, 장르별 데이터와 보류/의견 불일치 검증이 필요하다.
- 실험용 샘플은 장르 균형 있게 확보하고, 동일 그룹 내 비교와 그룹 간 비교를 구분한다. 좌우 위치 교차 및 동일 항목 재평가도 권고한다.

## 다음 개발 게이트
1. 실기기(Windows Chrome / Android Chrome)에서 2장·100장·1,000장, PC/모바일 반응형 UI 및 서비스워커 갱신을 확인한다.
2. 비교 결과 저장→새로고침→복원→CSV 일치, 대량 목록/메모리 사용량, 기존 GO/HOLD/DROP 무변경을 확인한다.
3. 사람 다수의 비교 기록으로 Bradley–Terry/Thurstone 모델을 교차검증하고, FGAesQ 공개 모델의 라이선스/모델 크기/성능/개인정보 처리 방식을 확인한 뒤 로컬 PC 추론 서비스 연동 여부를 결정한다.
