사진품질판정원 MOBILE v1.1 · GitHub Pages

변경사항
- 모바일 판정 토스트 축소 및 문구 정리
- GO/HOLD/DROP 캐릭터 버튼 확대
- 모든 사진 판정 완료 시 완료 화면 자동 표시
- 완료 화면에서 결과보기 / CSV 저장 / 새 사진 불러오기
- 선택한 저장폴더 아래 GO/HOLD/DROP 폴더를 자동 생성해 한 번에 복사 정리
- 설정: 완료창 자동 표시 / 버튼 진동 / 정리 폴더 선택

주의
- 웹 브라우저 보안 때문에 원본 사진을 강제로 이동/삭제하지 않습니다. 판정별 폴더에는 복사본을 저장합니다.
- 사진 자체는 서버로 업로드하지 않습니다.
